# AI Use Declaration

In accordance with the ANAVANDI Hackathon 2026 rules, we declare the following regarding the use of Artificial Intelligence tools during the development of CivicLens:

## AI Tools Used
- **Google Antigravity IDE (Agentic AI Assistant)**: Used extensively for pair-programming, boilerplate generation, and architectural design execution.

## What AI Assisted With
- **Initial Setup**: Bootstrapping the Next.js frontend and FastAPI backend architectures.
- **Data Modeling**: Generating the initial Pydantic schemas and MongoDB insertion scripts (`seed.py`).
- **Offline Synchronization Logic**: Assisting in the design and implementation of the IndexedDB offline caching wrapper and the backend idempotency key validation.
- **Component Styling**: Generating Tailwind CSS layouts for the Map markers and UI banners.
- **Documentation**: Assisting in formatting and structuring the final markdown documentation.

## What Was Manually Reviewed
All code generated by the AI assistant was manually reviewed, verified, and explicitly approved by the team. The routing algorithms, the idempotency implementation, and the offline fallback logic were heavily tested to ensure they met the strict hackathon stability requirements.

## Declaration
We confirm that we fully understand the implementation details of the entire codebase and did not rely on AI tools to blindly generate black-box systems (e.g., no autonomous app-builders were used). The project was built iteratively and is entirely manageable and explainable by the team.
